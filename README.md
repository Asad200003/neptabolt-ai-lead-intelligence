# Neptabolt AI Lead Intelligence Platform (MVP)

A configurable, AI-assisted lead intelligence platform designed to discover, enrich, score, and manage qualified B2B leads.

## Project Architecture & Stack
* **Backend API**: FastAPI (Python 3.11) + SQLAlchemy ORM
* **Database**: PostgreSQL 15
* **Task Management**: Background Tasks / Async Jobs
* **Frontend**: Next.js + TypeScript (`apps/web`)
* **Containerization**: Docker Compose
